这个页面不能双击打开
你现在用的是 file:// 协议，浏览器不允许这种页面加载 MediaPipe 的 WASM 识别模块，所以会报 Invalid security origin。这是浏览器的安全限制，改代码绕不过去。
两个办法，任选一个：
  1. 回到仓库目录，双击 start-demo.bat，它会自动起服务并打开浏览器
  2. 或者在仓库目录执行下面这行，然后访问 http://127.0.0.1:8000/demo/
python -m http.server 8000
用 127.0.0.1 或 localhost 打开属于安全上下文，摄像头也能正常授权。
