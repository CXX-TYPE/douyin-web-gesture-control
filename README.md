# 抖音网页版手势控制器

用摄像头识别手势，控制抖音网页版的视频切换、倍速与暂停。画面只在浏览器本地处理，不上传。

## 手势

| 手势 | 动作 |
|---|---|
| 比 1（只伸食指） | 上一个视频 |
| 比 2（食指 + 中指） | 下一个视频 |
| 竖大拇指 | 倍速切换 1× ↔ 2× |
| 五指张开 | 暂停 / 继续 |

保持 0.3 秒触发；触发后需收手或换手势才会再次生效。

## 安装（Edge）

1. 打开 `edge://extensions`，开启左下角「开发人员模式」
2. 点「加载解压缩的扩展」，选择本仓库的 `extension/` 目录
3. 打开抖音 → 按 `Alt + G` 开启 → 允许摄像头

> 目录名含中文时 Edge 可能加载失败。先建一个英文联接再选：
> `mklink /J "%USERPROFILE%\Documents\dy-gesture-ext" "<本仓库路径>\extension"`
